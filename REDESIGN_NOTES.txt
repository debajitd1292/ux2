PPU Operations Dashboard - redesign v2

Install:
1. Keep a backup of the current GitHub repository.
2. Upload/replace the contents of this package at the repository root, preserving the css/, js/, exec/, nonexec/, production/, seniority/, updates/ folders.
3. The plant-banner.jpg asset is used by css/style.css and must remain at the repository root.
4. The service worker was bumped to v2. After publishing, open the dashboard once while online and hard-refresh (Ctrl+F5). If the old version persists, clear this site's cached data/service worker in Chrome DevTools > Application, then reload online.

Changes:
- Redesigned home page with industrial process-plant banner, existing local BCPL logo, leadership strip, date/weather cards, GH/RH cards, compact current-shift banner, alerts and employee selectors.
- Current shift code/timing displays A 06:00-14:00, B 14:00-22:00, C 22:00-06:00, G 08:30-17:00, AB 06:00-22:00 and BC 22:00-06:00. Unknown shift codes do not get an invented time.
- Weather uses Open-Meteo and loads independently from CSV data; if unavailable, the dashboard continues and shows a weather-unavailable state.
- Initial data loader treats supporting datasets as optional; the current executive shift CSV remains required.
- Service worker v2 caches successful CSV responses under a query-independent URL and falls back to cache when offline.
- Existing non-home pages, data folders, CSVs and scripts are included unchanged except where noted above.

Validation performed:
- JavaScript syntax checked for app.js, loader.js, status.js, service-worker.js and pwa.js.
- Checked HTML for duplicate IDs and missing local script/link references.
- No full browser/device integration test was available in this environment. Please test the package in a separate branch before replacing the live deployment.
